# Security policy

## Supported version

Security fixes target the current `main` branch and the deployment version named
in the latest release. Older deployments should upgrade or be taken out of use.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository. Do not open a
public issue and do not include real inspection data, photos, contacts,
coordinates, credentials, tokens, or temporary passwords. Include the affected
commit, a minimal synthetic reproduction, impact, and any suggested mitigation.

Maintainers should acknowledge a report within three working days, establish a
private remediation plan, rotate affected secrets, and coordinate disclosure
after a fix is available. Operational incidents in a deployed institution must
also follow that institution's incident channel and legal obligations.
