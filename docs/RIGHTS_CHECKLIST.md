# Puerta de confirmación de derechos

No haga pública la historia Git hasta conservar fuera del repositorio un registro
breve que confirme que CEER controla el software original y autoriza publicarlo
bajo PolyForm Noncommercial License 1.0.0.

Texto sugerido:

> Confirmo que CEER posee o controla el software original revisado y autoriza su
> publicación bajo PolyForm Noncommercial License 1.0.0.

Registre firmante, capacidad, fecha, commit revisado y restricciones en el
sistema documental de CEER. No agregue firmas, correos privados o comprobantes
al repositorio.

La publicación debe usar una historia Git limpia creada desde la lista permitida.
La historia privada de preparación contiene una plantilla ATC retirada y no debe
volverse pública ni transferirse a la publicación final.

## Comprobación de terceros

- No se distribuyen formularios, plantillas, publicaciones ni carteles ATC-20.
- El nombre ATC-20 aparece únicamente como referencia metodológica factual y no
  como nombre de producto, publicidad, afiliación o respaldo.
- Cualquier futura reproducción, traducción o adaptación de material ATC exige
  una revisión separada de los términos vigentes y la autorización aplicable.
- Las marcas de una institución operadora requieren autorización específica de
  despliegue y nunca forman parte del valor predeterminado público.
- Los responsables de publicación verifican las condiciones vigentes de los
  datos DIVIPOLA y las licencias de dependencias.
